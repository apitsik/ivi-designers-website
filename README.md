# ivi designers website

Сайт команды дизайнеров ivi.

## Запуск

```
npm install
npm run dev
```

Шрифты IVI Sans в репозиторий не входят. Положите `IVI_Sans_Base_Regular.woff2` и `IVI_Sans_Base_Medium.woff2` в `public/fonts/`, иначе сайт покажет системный шрифт.

## Деплой

Сайт статичный. Собирать на машине, где есть `public/fonts/` (в репозиторий они не входят):

```
git pull
npm install
npm run build
```

Содержимое `dist/` заливается в корень сайта на сервере. Сайт должен лежать в корне домена (пути абсолютные: `/images/…`); для подпапки собирать с `vite build --base /подпапка/`.

Готовый конфиг nginx (https, gzip, кэш, заголовки) — `deploy/nginx.conf`, инструкция в его шапке.

Новые картинки перед коммитом жать: `npm run media:compress`.

## Музыка на первом экране

Мини-плеер в левом нижнем углу хиро играет подборку из `public/music/`. Чтобы собрать свою:

1. Положить mp3 (или m4a/ogg) и обложки (jpg/png, квадрат ~400×400) в `public/music/`.
2. Описать их в `public/music/playlist.json`:

```json
{
  "collection": "ivi tracks collection",
  "tracks": [
    { "title": "Тыктыгыдык", "artist": "", "cover": "/music/tyk.jpg", "src": "/music/tyk.mp3", "explicit": true }
  ]
}
```

- `title` — название трека; `artist` — вторая строка (если пусто, показывается название подборки `collection`); `explicit` — метка E.
- Треки играют по порядку и по кругу; музыка стартует только по клику на play (браузеры запрещают автозапуск звука), клик по обложке — следующий трек.
- Если плейлист пустой или не грузится, виджет не показывается.
- В репозитории лежит `placeholder.mp3` (синтезированный тон) — заменить на настоящие треки. Важно: выкладывать только музыку, на которую есть права (своя, с лицензией, royalty-free).
- При деплое на сервер `playlist.json` отдаётся без кэша (см. `deploy/nginx.conf`), сами mp3 кэшируются на месяц — при замене трека лучше менять и имя файла.
