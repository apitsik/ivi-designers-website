# AGENTS.md — сайт команды дизайна иви

Инструкция для Клода и других агентов, работающих в этом репозитории. Читать перед любой правкой.

## Что это

Одностраничный промо-сайт команды дизайна иви. Статичная сборка на Vite, чистый HTML/CSS/JS без фреймворков. Бэкенда нет: формы никуда не шлют, видео-попапы тянут плеер с Vimeo напрямую.

- Репозиторий: https://github.com/apitsik/ivi-designers-website (публичный)
- Макет: Figma «Сайт команды иви — Для экспорта», файл `a2iEsgfCdlIDTkovWFnY7L`. Верстать по макету, смотреть через Figma MCP (`get_design_context` / `get_screenshot` по node-id, который обычно указан в шапке модуля).
- Владелец проекта — дизайнер, сам не программирует. Объяснять изменения человеческим языком, без ссылок на внутренности инструментов.

## Как работать с репозиторием

- **Разрешения просить сразу, в начале сессии, одним заходом — не посреди работы.** Владелец это одобрил: лучше одно нажатие в начале, чем остановки по ходу. Нужны два:
  - **удаление файлов в папке проекта.** Без него падает сборка (vite чистит `dist`) и ломается git — он не может убрать свои `.lock`, и следующая команда валится с «File exists». Разрешение живёт только до конца сессии, поэтому запрашивается заново каждый раз. Если его всё же нет: собирать с `--emptyOutDir false`, а застрявший `.git/index.lock` переименовать, а не удалять.
  - **доступ к сайтам для браузера** (`figma.com`), со статусом «навсегда» — тогда больше не спросит.
- **Изменения — сразу коммитами и пушем в GitHub.** Патч-файлы и «вот диф, примени сам» не нужны. Обычно работаем в `main`; отдельная ветка — когда правка экспериментальная и её надо показать до влития (как было с `feat/media-compression`).
- Сообщение коммита — по-русски, в первой строке что сделано, ниже — зачем и детали. Примеры — в `git log`.
- Перед пушем из неглубокого клона: `git fetch origin main`, чтобы пуш не уехал с полным деревом.
- Показывать результат — собранной версией: `vite build --base ./`, абсолютные пути `/images/…` в сборке заменить на относительные, опубликовать как артефакт. У сайта нет шрифтов в репозитории, в превью будет системный шрифт — это нормально, предупредить.
- Локально у владельца проект лежит в `~/Documents/ivi/designers website/claudeCode/` (это git-клон); рядом в `Assets/` и `images/` — исходники стикеров и картинок, в репозиторий они не входят.

## Команды

```
npm install          # зависимости: vite, lenis, matter-js, sharp
npm run dev          # localhost:5173 (.claude/launch.json запускает то же)
npm run build        # dist/
npm run preview      # отдать dist/ на localhost:4173
npm run media:compress   # сжать новые картинки в public/ и assets/logos (sharp)
```

## Структура

```
index.html          вся разметка страницы, секции по порядку; критичный CSS прелоадера в <head>
src/main.js         точка входа: импорт CSS модулей, инициализация секций по порядку, прелоадер последним
src/styles.css      база: шрифты, переменные, nav, hero, общие правила, тёмная тема (.theme-dark)
src/reveal.js       общее проявление заголовков «из блюра» по словам — используют все секции
src/smooth-scroll.js  Lenis; экспортирует инстанс lenis для якорей и блокировки под попапами
src/<section>.js + .css   по модулю на секцию (см. ниже)
assets/logos/       6 кадров логотипа навбара (logo-01.svg … logo-06.png); подхватываются через import.meta.glob
public/             статика как есть: images/, stickers/, video/, music/, cursors/, фавиконы
public/fonts/       IVI Sans Base — в .gitignore (лицензия), кладутся вручную; без них системный шрифт
scripts/compress-media.js   сжатие PNG (палитра imagequant) и JPG (mozjpeg q82), имена и форматы не меняет
deploy/nginx.conf   прод-конфиг: https, gzip, кэш по папкам, заголовки; инструкция в шапке
```

### Секции сверху вниз (порядок в index.html и main.js)

| Секция | Модуль | Суть |
|---|---|---|
| прелоадер | `preloader.js` | чёрный экран, перебор кадров лого с разгоном/торможением, старт и финиш на logo-01, уезд вверх; ждёт hero-видео, шрифты и картинки без `lazy` |
| nav | `nav-logo.js` | лого в шапке, по ховеру покадровая анимация из `assets/logos` |
| hero | `cursor-scrub.js`, `hero-stickers.js`, `hero-player.js` | видео скрабится курсором по горизонтали; тап клеит стикеры; мини-плеер с плейлистом из `public/music/playlist.json` |
| showreels | `showreels.js`, `video-modal.js` | плашка наезжает на hero, параллакс карточек, попап с Vimeo по `data-vimeo` |
| extra-text | `extra-text.js` | розовая плашка выезжает, в середине экрана страница переключается в тёмную тему |
| team | `team.js` | сцена залипает на 3 шага скролла, постер + каскад стикеров на шаг (данные в `data-*` на `<img>` в HTML) |
| awards | `awards.js` | список наград, за курсором плывёт картинка проекта; данные в массиве в модуле |
| articles | `articles.js` | 3D-колода карточек, драг, бесконечный список; данные в массиве `ARTICLES` |
| grid | `grid.js` | сетка иллюстраций и видео; видео играют только в зоне видимости |
| vacancies | `vacancies.js` | след фото за курсором, модалка резюме |
| footer | `footer.js` | Matter.js: логотипы осыпаются и падают в плашку, можно таскать |

Контент правится либо прямо в `index.html` (team, grid, showreels), либо в массиве в начале модуля (articles, awards). CMS нет.

## Договорённости по коду

- Каждый модуль начинается с комментария по-русски: что делает секция, откуда референс в Figma (node-id), как устроена анимация. Поддерживать при правках.
- Экспорт модуля — одна функция `initXxx(element)`, вызывается из `main.js`; если элемента нет — тихо выйти.
- Заголовки H2 проявляются через `reveal.js` (`splitWords` + `observeReveal`) — не изобретать своё проявление.
- Все анимации уважают `prefers-reduced-motion`: без движения или короткий фейд.
- Скролл-эффекты считаются от `scrollY`/IntersectionObserver, движение сглаживается lerp'ом — Lenis крутит обычный window-скролл.
- Переходы и изинги — через CSS `transition`/`cubic-bezier`, JS меняет классы (`is-visible`, `is-leaving`, …). `requestAnimationFrame` — только где нужен непрерывный расчёт (параллакс, физика, драг).
- Пути к статике абсолютные (`/images/…`); сайт должен лежать в корне домена. Для подпапки — `vite build --base /подпапка/`.
- Видео в сетке: `muted playsinline loop`, `preload="metadata"`; hero-видео — `preload="auto"`, без звука.

## Медиа

- Новые картинки класть в `public/images/<секция>/` или `public/stickers/` с теми же схемами имён, что рядом, и перед коммитом прогонять `npm run media:compress`. Скрипт перезаписывает файл только если он стал меньше на 3 %+, иконки пропускает.
- PNG держать для стикеров и всего с прозрачностью, JPG — для фото. WebP/AVIF и `srcset` сейчас не используются.
- Видео жать ffmpeg-ом вручную, рецепт в конце `scripts/compress-media.js` (H.264, crf 24–27, без аудио, ≤30 fps, ширина ≤1280 для сетки).
- Не коммитить исходники из `Assets/`, `assets/` (кроме `assets/logos/`) и `public/fonts/` — они в `.gitignore`.

## Деплой

Собирать на машине владельца (там есть шрифты), заливать содержимое `dist/` в корень домена. nginx-конфиг — `deploy/nginx.conf`: `index.html` и `playlist.json` без кэша, `/assets/` навсегда (хэши в именах), картинки/видео/шрифты/музыка на месяц. Подробнее — README, раздел «Деплой».

## Чего не делать

- Не вводить фреймворки, TypeScript, препроцессоры, сборщики кроме Vite.
- Не менять имена и форматы файлов в `public/` без необходимости — на них завязаны `index.html`, модули и кэш на сервере.
- Не переписывать чужие модули «заодно»: правка — только в той секции, о которой просили.
- Не коммитить шрифты IVI Sans и музыку без прав.
